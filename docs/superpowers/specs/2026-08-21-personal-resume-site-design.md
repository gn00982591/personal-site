建立一個以求職與專業介紹為目的的響應式單頁網站，呈現企業系統開發與系統分析能力。網站公開部署於 GitHub Pages，內容不得揭露現職公司、客戶、內部系統名稱、實際單號、資料表名稱或其他機密資訊。

## 3. 技術架構

- Vue 3
- Vite
- 純前端單頁網站
- 不使用後端、資料庫、登入或追蹤功能
- 履歷文字集中於獨立資料模組，避免內容與版面耦合
- 使用 GitHub Actions 自動建置並部署到 GitHub Pages
- 程式碼加入必要的繁體中文註解
- 避免不必要套件，優先使用原生 CSS 與少量 JavaScript

## 5. 視覺設計

- 預設使用淺色主題
- 背景：米白與淺灰
- 主要文字：深藍灰
- 重點色：藍綠色
- 卡片使用細邊框、柔和陰影與足夠留白
- 不使用黑色作為主要背景
- 可提供深色模式切換，但預設必須為淺色
- 深色模式以深藍灰為背景，不使用純黑色
- 以專業、安定、清楚為主，不使用過度花俏的動畫

## 6. 響應式與無障礙

- 支援桌面、平板與手機
- 導覽、按鈕及連結可使用鍵盤操作
- 提供清楚的 focus 樣式
- 維持足夠的文字與背景對比
- 尊重 `prefers-reduced-motion`
- 使用語意化 HTML 區塊與標題階層
- 互動控制需有可理解的標籤

## 7. 動態效果

- 區塊進入視窗時使用輕微淡入
- 導覽列依目前區塊呈現狀態
- 主題切換結果可儲存在瀏覽器本機
- JavaScript 無法執行時，主要履歷內容仍需可閱讀

## 8. 部署方式

- 原始碼存放於 `main` 分支
- GitHub Actions 執行安裝、建置與 GitHub Pages 部署
- Vite 設定正確的 Repository base path
- 每次推送到 `main` 後自動重新部署

## 9. 驗收標準

1. 首頁可正常顯示職稱、摘要與導覽。
2. 所有規劃區塊皆具有實際內容，不出現假資料或未完成的佔位文字。
3. 不出現公司、客戶、內部系統名稱、單號及機密識別資訊。
4. Email 與 GitHub 連結可正確開啟。
5. 桌面與手機寬度下內容均可閱讀，且沒有水平捲動。
6. 鍵盤可操作所有互動元件。
7. Production build 成功。
8. GitHub Pages 部署流程設定完成。
