# 企業系統開發工程師｜個人履歷

以 Vue 3 與 Vite 建立的響應式單頁履歷網站，呈現企業系統開發、系統分析、資料整合與問題追查能力。

## 內容原則

- 所有代表案例皆經匿名化。
- 不公開公司、客戶、內部系統名稱、單號或資料表名稱。
- 不使用虛構年資與量化成果。

## 開發


```bash
# 安裝依賴
npm install

# 啟動本機開發環境
npm run dev

# 執行測試
npm run test

# 建立正式版本
npm run build
```

## 技術

- Vue 3
- Vite
- Vitest
- 原生 CSS
- GitHub Actions／GitHub Pages
